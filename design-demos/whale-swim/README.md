# 鲸鱼慢游与水泡

空会话（hero）页里那尾鲸鱼的游动改版。日期：2026-11-11。

## 改了什么

**游得更慢、更像真的游。** 周期从 9 秒拉到 24 秒，路径从「在两个边缘之间乱窜」改成沿标题行横穿整片开阔水面的一次长行程：只有缓慢的起伏（上下 76px）和两端各一个大转弯，尾巴约一秒半摆一次。转向时身体压成侧身（scaleX 0.06）再翻面，像鱼真的转身。

**顺带修掉一个旧毛病。** 之前「转向」用的是挂在父元素上的缩放，父级缩放会把子级的位移一起缩小——于是鲸鱼每次转向都被拽回行首再冲出去。实测一次转向瞬间位移 700px，肉眼是「弹回去再出发」。现在位移与身体形变合并到同一条关键帧、同一个 transform 里，路径全程连续（按 2% 相位采样逐点验证，无跳变）。

**加了水泡。** 游动时从背上冒出一串小水泡，缓慢上浮、微微后飘，到顶时炸开（环快速放大并淡出）后移除。

**修正朝向。** 宿主画的那尾鱼**头在左、尾在右**，我先前按「正缩放 = 朝右」来写，于是它整程都在倒着游。现在缩放的符号负责朝向：向右游时镜像，向左游时不镜像；镜像段的旋转角也一并取反，因为镜像过的元素在屏幕上转向相反。已按相位 30%（向右）与 70%（向左）分别截图核对，鱼头都顺着行进方向。

## 实现

| 项 | 做法 |
| --- | --- |
| 游动 | `src/client/styles/sidebar-layout.ts` 的 `dsh-enhance-whale-travel`，一条关键帧同时写位移、旋转和身体形变 |
| 水泡绘制 | 同文件的 `.dsh-enhance-bubble` + `dsh-enhance-bubble` 关键帧（样式表负责画和动） |
| 水泡投放 | `src/client/whale-bubbles.ts`，脚本只负责「在鲸鱼此刻所在的位置放一个泡」并回收 |
| 找鲸鱼 | 靠插件自己的动画名 `dsh-enhance-whale-travel` 反查元素，不依赖宿主哈希类名 |
| 减弱动态效果 | 动画在 `@media (prefers-reduced-motion: no-preference)` 内，系统开启时不跑，自然也没有水泡 |

样式表做不到「在鱼此刻所在的地方放一个泡」——水泡必须在鱼的实时位置上生成再被留在原地，所以这一小步由脚本完成；泡本身仍然是样式表画的。

## 验证

在隔离的 dsh-web 实例上实测（真实宿主 UI，非模拟）：

- 游动：按 2% 相位逐点采样，路径连续无跳变；全程 x 886→1272→889，y 317→393，不压到输入框
- 转向：50–54% 与 94–98% 两处，scaleX 压到 0.06（侧身）后翻面
- 水泡：稳定 3–5 个存活，各自带随机大小（5–9px）与时长（2.2–3.0s），`animationend` 后移除
