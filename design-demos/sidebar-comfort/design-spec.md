# Workspaces 侧栏舒适性 redesign · 三方向共同规范

## 任务与使用场景
这是 DeepSeek Harness 桌面端工作区侧栏的高保真静态 redesign，不是宣传页、Dashboard 或移动 App。用户每天长时间在项目与会话之间切换，需要快速定位当前工作，同时能扫读中文会话标题和相对时间。已有参考是用户提供的 468×1864 深色侧栏截图，已有项目代码也表明当前插件采用较紧行高和较统一文字颜色。设计要保留 macOS 桌面工具的原生、安静、高效感，不发明功能，不增加无关数据、统计、营销文案或装饰插画。

## 输出规格
- 每个方向一个独立、可双击打开的纯 HTML/CSS 文件，固定画布 420×1680 px；截图同为 420×1680，deviceScaleFactor 2。
- 三版最终并排为一张对比设计图，因此单版尺寸、内容顺序和真实数据必须一致。
- 页面内只呈现侧栏本体，不加展示页标题、设计师署名、参数标注或多余外框。
- 中文使用 -apple-system / BlinkMacSystemFont / PingFang SC；数字清晰，时间右对齐。
- 所有图标用统一的简洁线性 SVG，默认 16px，顶部与底部工具 18px，线宽 1.5–1.7，点击热区视觉容器 28–32px。
- 头像必须使用 assets/avatar.png；不可 SVG 画人，不可换成字母或插画。

## 共同布局与可用性底线
- 主画布采用固定纵向 flex；列表区可延展，底部账户工具固定，不与 Ungrouped 挤在一起。
- 侧栏左右基础内边距 12px；顶部标题区约 52px；项目标题 36–40px；会话行 38–42px；折叠项目 34–38px；项目组间留白 8–12px。
- 正文标题 13px，项目名 14px，Workspaces 17px，时间与展开更多 12px。中文标题不能低于 13px，辅助标签不低于 12px。
- 会话文字与时间至少 12px 间距；标题只截断一次；时间宽度稳定且右对齐。
- 当前项目由图标颜色、字重或小状态共同体现；当前会话必须一眼可见，但不能靠高亮胶囊或大光晕。
- 主文字对比度 ≥4.5:1，辅助文字尽量 ≥4.5:1；不要使用纯白眩光文字。
- 选中背景圆角 8px，不使用夸张全圆胶囊；颜色克制，选中态除颜色外还有形状/状态差异。
- 不添加厚重投影、紫色渐变、霓虹 glow、每行卡片边框、emoji、装饰性图片。
- 保持真实图标和项目的阅读路径：Workspaces → 当前项目组 → 当前会话 → 其他项目 → 底部工具。

## 视觉母题
form 来自「工作区树 + 当前运行会话」：纵向细引导线、统一行网格、当前会话的小运行环，构成安静的工作台索引。不是用装饰来制造风格，而是让树状层级和当前状态本身成为视觉特征。

## 三方向约束
A · 克制深灰 / Neutral Focus：背景近中性石墨色，当前会话以低饱和雾蓝底 + 极细运行状态体现，文字层级最均衡；行高舒适、分组明确。参考原生 macOS Finder 与高质量桌面工具，但整体仍是本项目自定义，不照搬其他产品。
B · 暖墨低蓝光 / Warm Graphite：背景略暖，文字微暖白，强调色降低蓝紫感，采用柔和青蓝；更多依靠留白与细分隔，不要彩色底块堆砌。适合夜间长时间阅读，中文最柔和。
C · 编辑器精密网格 / Compact Precision：比 A/B 更紧凑，层级通过细树线、对齐和字重体现；当前态更几何、更利落，图标与时间的对齐最严谨。仍必须满足 13px 正文、38px 会话行和舒适性底线，不做终端风，不使用等宽字作为正文。

## 交付判断
这是静态视觉初稿，不改插件代码，不承诺交互已实现。三版同内容仅改变视觉处理；用户选定后再深化。
